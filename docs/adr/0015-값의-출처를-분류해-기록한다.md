# ADR 0015: 코드와 설정의 기본값·한도의 출처를 분류해 기록한다

상태: 채택 (2026-10-29, 표준성 점검 '전 영역' 항목, 헤드 결정표 D106). 값은 바꾸지 않았다.

## 맥락
2026-10-29 표준성 점검(docs/audit/standards-2026-10-29.md)이 이유 없는 임의 값(N-)을 지적했다. 이 ADR은 값을 바꾸지 않고 각 값이 **측정, 표준, 제약, 기본 관행/미상** 중 어디서 왔는지와 측정했는지를 적는다. 측정 계획도 적지 않는다(측정하지 않았다는 사실만 적는다).

분류: **측정** = 이 영역이 실제 데이터나 부하로 재서 정했다. **표준** = 이름 있는 표준·사양에서 왔다. **제약** = 다른 시스템·파일 시스템·계약이 정한 한계다. **미상** = 위 셋이 아니며 시작값으로 두었다. 이 표에 **측정**으로 분류된 값은 없다. 이 영역은 그 어떤 한도도 부하 시험으로 정한 적이 없다.

## 왜 값을 바꾸지 않는가
결정표(D106)가 '값을 바꾸지 않고 출처를 기록'하라고 했다. 측정하지 않은 값을 다른 측정하지 않은 값으로 바꿔도 근거는 생기지 않는다.

## 결과
얻는 것: 값마다 출처 분류가 한곳에 있어, 측정 없이 굳은 값을 찾을 수 있다. 감수하는 것: 이 표는 손으로 쓴 것이라 코드에 새 상수가 생기면 어긋날 수 있다(자동 검사는 없다).

## 되돌리는 조건
부하나 실제 데이터로 값을 재서 정하면 해당 행을 '측정'으로 바꾸고 측정 방법·결과를 쓴 새 ADR을 둔다.
