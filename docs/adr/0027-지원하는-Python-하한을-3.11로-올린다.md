# ADR 0027: 지원하는 Python 하한을 3.11로 올린다

## 상태
채택(2026-11-08).

## 맥락
`pyproject.toml`의 `requires-python`은 `>=3.10`이었는데, 구조 시험(`tests/test_structure.py`)이 `tomllib`을 import한다. `tomllib`은 3.11부터 표준 라이브러리에 있어 3.10에서는 시험이 실패한다. 선언한 지원 범위와 시험이 요구하는 범위가 어긋났다. 시험 의존 잠금(`requirements.lock`)에는 `tomli`가 없다.

## 결정
`requires-python`을 `>=3.11`로 올린다. README의 전제 문구도 맞춘다.

## 왜
- 이 리포 안에서 확인되는 사실만 근거로 한다. 이미지 기반은 `Dockerfile`의 `PYTHON_IMAGE`(`python:3.12-slim`, digest 고정)이고, 운영으로 나가는 인터프리터가 3.12다.
- 시험이 쓰는 `tomllib`은 3.11부터 표준이다. 표준 라이브러리를 쓰는 편이 시험 전용 의존(`tomli`)을 잠금에 더하고 조건부 import를 두는 것보다 적게 건드린다.
- 3.10 지원을 시험한 근거는 리포에 없다(측정하지 않았다).

## 검토한 대안과 버리는 이유
- `tomli`를 시험 의존에 더하고 `tomllib`이 없을 때만 import한다: 시험하지 않은 3.10 지원을 유지하려고 의존과 분기를 더한다. 운영 인터프리터가 3.12이므로 얻는 것이 없다.

## 결과
얻는 것: 선언과 시험 요구가 일치한다. 감수하는 것: 3.10에서는 설치할 수 없다(운영 이미지는 영향 없다).

## 되돌리는 조건
3.10을 실제로 지원해야 하는 설치처가 생기면 `tomli` 잠금과 조건부 import로 대체하는 새 ADR을 쓴다.
