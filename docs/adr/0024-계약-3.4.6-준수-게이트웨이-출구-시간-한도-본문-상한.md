# ADR 0024: 계약 3.4.6 준수 — 게이트웨이 출구, 시간 한도, 게시 본문 상한, 감시 면

상태: 채택 (2026-11-04). 대체: ADR 0020의 "전 경로 denied"(감시 경로 부분만). 계약 boundary-contracts v3.4.6(RUNTIME R1.8·R5.1·R8.1·R10.3·R10.5·R10.8·R10.11·R10.13, CONVENTIONS 13절).

## 맥락
계약 3.4.x는 영역 밖 호출을 자기 영역 게이트웨이의 CONNECT 터널로만 내게 하고, 감시 경로와 게시 본문 상한·시간 한도를 정했다. 이 영역의 잡은 I1·I7을 읽고 I2에 게시한다.

## 결정
- 잡의 이웃 클라이언트(I1·I7)와 I2 게시 클라이언트는 `egress_proxy_from(os.environ)`이 꺼낸 `OPENIT_EGRESS_PROXY` 하나만 `egress_proxy`로 받는다(R9.1: 환경을 통째로 쓰지 않는다). 설정의 `kwargs`가 직접 정하면 그 값이 우선한다.
- `Exposure.egress`는 `question-authoring`, `ops-feedback`(INTERFACES 한눈에: synthetic-data는 I1·I7을 읽는다). 게시(I2)는 dataset-store 자기 서비스라 영역 안이다. I2 경로는 계속 `denied`, `/healthz`·`/readyz`·`/metrics`는 `none`(R5.1·R10.11).
- `/metrics`는 Prometheus 텍스트(`dataset_store_up`, 상태 코드별 요청 수). 인증 없음, 인증 실패 횟수 제한 밖, 저장소가 멈춰도 200(프로세스 안의 값만).
- `/readyz` 아님 표기는 `not_ready`(HealthStatus).
- 503 내부 오류 로그는 예외 종류와 위치(파일:줄)만 남기고 메시지는 남기지 않는다(R8.1). 로그 쓰기 실패는 요청을 실패시키지 않는다(R10.5).
- 시간 한도(R10.3): 사슬 표에 없는 읽기(I1·I7) 클라이언트 `timeout` 기본 30초, tar 게시(I2) 300초. 둘 다 계약의 시작값이며 측정하지 않았다.
- 게시 본문 상한(R10.13): `DATASET_STORE_MAX_BODY` 기본 1GiB. 계약은 8GiB(`max_tar_bytes`) 이하이고 게시받기로 한 가장 큰 단일 데이터셋 이상이어야 한다고 한다. 가장 큰 데이터셋의 크기는 측정하지 않았다(미정). 값은 환경 변수로 바꾼다. 같은 값을 `Exposure.routes[].max_body_bytes`(계약 3.4.7)로 `/v1/datasets` 경로에 선언해 영역 게이트웨이가 같은 값으로 413을 낸다(시험 `test_exposure_table_matches_code_routes`가 서비스 기본값과의 일치를 본다).
- 잡 선언에 `timeout_seconds` 1800(R9.2·R9.3). 근거: 기본 3600초 상한의 절반으로 잡은 시작값이고 실제 실행 시간은 측정하지 않았다.
- 게시는 임시 폴더에 풀어 검증한 뒤 rename으로 한 번에 놓는다(전부 또는 전무, R10.8). 도중에 저장이 실패하면 503이고 읽히는 버전·임시 폴더가 남지 않으며(시험 `test_publish_failing_midway_leaves_no_trace_and_resend_works`) 같은 요청을 다시 보내면 201, 또 보내면 200, 다른 내용이면 409다.

## 왜
위 조항이 요구한다. 환경 변수 이름은 계약 `CommonEnv`의 `OPENIT_EGRESS_PROXY` 하나만 쓴다(새 이름 없음).

## 검토한 대안
- 프록시를 `HTTPS_PROXY`로 받음: 계약 클라이언트가 읽지 않고 R9.1에 어긋난다.
- DB 도입: 해당 없음. 저장소는 파일 시스템이다(ADR 0008). R4.1의 "끊긴 DB 연결 재접속"은 대상이 없고, `/readyz`가 저장소 쓰기를 매번 확인하므로 복구되면 재시작 없이 ready가 된다(시험 `test_health_bodies_follow_health_status_and_not_ready_spelling`).

## 결과
얻는 것: 영역 밖 호출이 게이트웨이 한 길로만 나간다. 감수하는 것: 시간 한도·본문 상한·잡 한도는 측정하지 않은 시작값이다.

## 되돌리는 조건
계약이 값을 바꾸거나 실제 데이터셋 크기·잡 시간을 측정하면 새 ADR로 대체한다.
