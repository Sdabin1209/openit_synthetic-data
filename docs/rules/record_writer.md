## 7. Record Writer 규칙
1. 저장 결정은 판정을 슬롯별로 펼친 것이다. 정상(첫 답) → 첫 저장, 정상(같은 값) → 없음(확인 대기 버림만), 정정 → 새 revision(받아들임이면 확인 대기 받아들임), 충돌 → 확인 대기 둠, 모름·거절 → 모름 기록·거절 기록, 확인 응답만의 받아들임·버림 → 확인 대기 받아들임·버림, 무효화 대상 문항의 슬롯 중 현재값이 없음이 아니거나 확인 대기가 있는 슬롯 → 무효화(기록이 없는 슬롯은 내지 않는다). 저장 결과 요약의 무효화된 문항은 실제로 무효화한 슬롯이 있는 문항만이다. 애매·누락·선행 불충족은 저장하지 않는다. 변경 없는 슬롯은 내지 않는다. 무효화를 먼저 낸다. 판정의 확인 대기 처리가 버림인데 그 슬롯의 동작이 확인 대기를 지우지 않는 동작(모름 기록·거절 기록·새 revision)이면, 그 슬롯에 확인 대기 버림을 하나 더 내고 그 동작 뒤에 둔다. 한 슬롯에 결정이 둘인 경우는 이것뿐이다.
   - 왜: 저장소가 판단 없이 반영하려면 동작이 다 정해져 있어야 한다. 무효화를 먼저 내야 같은 턴에 다시 받은 값이 지워지지 않는다. 모름 기록·거절 기록·새 revision은 9-2절 표대로 확인 대기를 그대로 두므로, 6절 2·5가 버리라고 한 확인 대기를 지울 결정이 따로 필요하다(C8c, X2, N17, R13).
2. 문항 전체 판정은 그 문항의 모든 슬롯(상태 판정이 뺀 슬롯 제외)으로 펼친다.
   - 왜: 응답 기록은 슬롯 단위다.
3. 확인 대기 ID는 확인 대기 둠마다 새로 만든다(기존 값을 읽지 않는다).
   - 왜: 같은 슬롯에 새 충돌 값이 오면 이전 확인의 "네"가 새 값을 받아들이지 않게.
